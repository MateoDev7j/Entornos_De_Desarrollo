# 🐾 Proyecto: Gestión de Animales (UD5)

Este proyecto forma parte de la asignatura de **Entornos de Desarrollo**. El objetivo principal es aplicar técnicas de **documentación con Javadoc**, gestión de versiones con **Git** y organización de proyectos Java.

## 📋 Descripción
La aplicación es un ejemplo de Programación Orientada a Objetos (POO) que modela el comportamiento de diferentes animales mediante herencia.

## 🛠️ Estructura del Proyecto
El código se divide en las siguientes clases:

*   **`Animal.java`**: Clase base (superclase) que define los atributos y métodos comunes.
*   **`Perro.java`**: Clase que hereda de Animal con comportamientos específicos de caninos.
*   **`Gato.java`**: Clase que hereda de Animal con comportamientos específicos de felinos.
*   **`Ejercicio5_1.java`**: Clase principal (Main) que ejecuta la lógica y las pruebas del programa.

## 📖 Documentación Javadoc
La documentación técnica detallada (clases, parámetros y retornos) ha sido generada automáticamente y se encuentra disponible en la carpeta:
`./dist/javadoc/index.html`
